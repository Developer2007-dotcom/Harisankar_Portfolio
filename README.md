# Harisankar V H — Django Portfolio

Django portfolio with Home, About, Work, Skills and Contact templates, shared styling, portrait, project covers and favicon, plus a server-side enquiry form that delivers through Resend.

## Deploy on Vercel

Start with [DEPLOYMENT.md](DEPLOYMENT.md). Vercel detects the root `manage.py`, automatically collects static files, and serves them through its CDN. Configure production secrets and Resend values in Vercel project settings before deployment.

## Run locally on Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Edit `.env`, then run:

```powershell
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/`.

## Resend and content

- `RESEND_API_KEY` is private. Keep it in local `.env` or Vercel environment variables, never in source control.
- Production `RESEND_FROM_EMAIL` must use a sender on a domain verified in Resend. `CONTACT_TO_EMAIL` is the destination inbox.
- The form validates submissions and sends through Resend, with the visitor's address as reply-to. It does not store enquiries in a database.
- Replace the Facebook profile URL placeholder in `portfolio/templates/portfolio/base.html`.
- SEO titles and descriptions are in the page templates. `/robots.txt` and `/sitemap.xml` are generated by Django.

## Project structure

- `config/` — settings and Django entry points.
- `portfolio/views.py`, `forms.py`, `email_service.py` — page routes, contact form and Resend integration.
- `portfolio/templates/portfolio/` — shared base, five pages and email template.
- `portfolio/static/portfolio/` — CSS, JavaScript, profile picture, favicon and project covers.
- `DEPLOYMENT.md` — Vercel, Resend and SEO setup.

The project uses Django 6.1.1, Resend's Python SDK 2.x, python-dotenv and WhiteNoise for local static serving. Vercel serves production static files from its CDN.
